M2: Бильярд на гладком столе

Моделируем упругое столкновение двух бильярдных шаров на гладком столе.
Решаем уравнения движения (2-й закон Ньютона) для деформируемых шаров,
контактная сила по закону Гука (F ~ delta) или Герца (F ~ delta^1.5).

Рассмотрены случаи:
- лобовой удар, равные и разные массы
- оба шара движутся навстречу
- удар под углом (с прицельным параметром b)
- промах

Файлы:
main.py - модель, проверка входных параметров, один расчёт с графиком (параметры в начале файла)
test.py - тесты: сравнение с теорией и проверка входных данных
experiments.py - серии расчётов для отчёта, графики сохраняются в results/
report.txt - выбор параметров интегрирования, ограничения, результаты и выводы

Запуск (из папки M2):
python main.py
python -m pytest test.py
python experiments.py

Если параметры недопустимые (например скорость больше скорости света или шары перекрываются), main.py пишет ошибку и завершается.
